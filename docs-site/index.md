[English](en/quick-start.md) | [ภาษาไทย](th/quick-start.md)

---

TomPanel is an open-source, web-based control panel for managing a single Linux VPS. One administrator, multiple websites, operations-first.

## Get started

```bash
git clone https://github.com/Dhanabhon/tom-panel.git
cd tomlpanel
sudo sh scripts/quick-install.sh
```

## What you can do

- Manage static, PHP, and reverse-proxy sites
- Domains with DNS + SSL certificates (Let's Encrypt)
- File Manager with trash and archives
- Site-scoped MariaDB databases + phpMyAdmin
- WordPress and Laravel installers
- Backups with encrypted S3/R2 upload
- Service controls, log viewer, system metrics
